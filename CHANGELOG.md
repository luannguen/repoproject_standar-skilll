# Changelog

All notable changes to this template are documented here. The format follows Keep a Changelog principles and semantic versioning for the template layer.

## [Unreleased]

### Conditional after clone

- Add application-specific build, test, security, dependency, deployment, recovery, and observability controls when the real stack and risk are verified.

## [1.2.0] - 2026-07-16

### Added

- Apache License 2.0 for clear global reuse rights.
- Two-layer Custom Skill architecture with 14 technology and 13 domain reusable modules.
- Stack/domain detection, project activation bindings, evidence-backed overlay policy, compatibility matrix, and lightweight stack profiles.
- Official upstream ledgers for every technology skill and 30 Custom Skill anti-patterns.
- Custom Skill lint, detector synchronization, and 12 manifest-driven routing fixtures in unified validation.

### Changed

- GitHub Actions dependencies are pinned to immutable full commit SHAs.
- Constitution, Bootstrap, Orchestrator, AGENTS, and onboarding now keep Standard Skills separate from task/scope-filtered Custom Skills.
- Template version advanced to 1.2.0; only HIGH-confidence `github-ci` is active in the uninstantiated repository.
## [1.1.0] - 2026-07-16

### Added

- Project onboarding and bootstrap-governance skill.
- Template manifest and machine-readable project profile.
- Cross-platform unified validation and routing fixtures.
- Repository governance, security, contribution, release, ownership, and collaboration baselines.
- Windows and Linux GitHub Actions quality gates and GitHub Actions dependency updates.

### Changed

- Routing now treats a cloned, uninstantiated repository as a dedicated onboarding workflow.
- Path handling in validators is portable across Windows PowerShell and PowerShell 7 on Linux.

## [1.0.0] - 2026-07-16

### Added

- Project Constitution, approval gates, Bootstrap router, skill and workflow registries.
- Project Orchestrator, Project Memory, production capability skills, workflows, and validation reports.
